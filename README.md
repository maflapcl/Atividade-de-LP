# CRUD de Produtos — Next.js e Prisma

Projeto desenvolvido para a atividade prática da disciplina **Linguagem de Programação IV — Internet**, com o objetivo de construir uma aplicação CRUD utilizando Next.js e Prisma 7.

## Tecnologias utilizadas

- Next.js
- React
- Prisma ORM 7
- MySQL
- JavaScript

## Funcionalidades

A aplicação permite realizar as operações básicas de gerenciamento de produtos:

- **Create:** cadastrar produtos.
- **Read:** listar e consultar produtos.
- **Update:** editar produtos cadastrados.
- **Delete:** excluir produtos.

## Como executar o projeto

### 1. Instalar as dependências

```bash
npm install
```

### 2. Configurar o banco de dados

Configure a conexão com o banco de dados MySQL conforme as configurações do projeto.

Crie o arquivo `.env` com as variáveis de ambiente necessárias.

### 3. Executar a aplicação

```bash
npm run dev
```

Depois, acesse http://localhost:3000 pelo navegador.

## Objetivo

Praticar o desenvolvimento de uma aplicação web utilizando Next.js, integração com banco de dados MySQL e Prisma ORM para realizar operações CRUD.
